# Pokhara Local

A full-stack web app for discovering local businesses and services in Pokhara, Nepal — electricians, tutors, mechanics, and more.

## Features (in progress)
- Browse and search local business listings
- Filter by category and location
- User authentication
- Reviews and ratings
- Favorites/saved listings

## Tech Stack
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Frontend:** React (coming soon)

## Current Status
🚧 Under active development. Backend API is functional with a working listings endpoint.

## API Endpoints (so far)
- `GET /api/listings` — returns all listings

## Running Locally
1. Clone the repo
2. `cd server && npm install`
3. Set up a PostgreSQL database named `pokhara_local`
4. Run `npm run dev` to start the server on `http://localhost:3000`
